      Configuração da API (recomendado)

      A chave fica neste perfil e é enviada ao Google ao consultar os uploads.

      Como criar uma chave de API
      1. Entre com sua conta Google e crie um projeto no Google Cloud. Se já tem um projeto, selecione-o no topo do console.
      2. No mesmo projeto, abra a YouTube Data API v3 e clique em Ativar.
      3. Abra Credenciais e escolha Criar credenciais → Chave de API.
      4. Em Restrições de aplicativo, selecione Nenhuma. Em Restrições de API, escolha Restringir chave e selecione apenas YouTube Data API v3. Confirme em Criar ou Salvar.
      5. Copie a chave, volte a este painel e clique em Salvar chave depois de colá-la. Teste com Criar fila.
